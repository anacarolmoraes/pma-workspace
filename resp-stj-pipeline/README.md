# RESP STJ Pipeline

Sistema multiagente para elaboração de Recurso Especial ao STJ com Claude Code + NotebookLM via MCP.

## Objetivo
Produzir um RESP tecnicamente viável, com base:
- no processo concreto;
- na técnica recursal do STJ;
- na matéria de fundo;
- na jurisprudência atualizada.

## Fontes
- NB1 = processo concreto
- NB2 = RESP
- NB3 = curso da matéria
- NB4 = jurisprudência atualizada

## Regra de ouro
Nenhuma peça deve ser redigida antes de a tese sobreviver aos filtros:
1. realidade processual
2. técnica recursal
3. jurisprudência atual
